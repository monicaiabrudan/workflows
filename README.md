
***Short Course on Reproducible Genomics using Containers, Workflow Managers and Cloud Computing***


*29-30 October 2026, Babes-Bolyai University, Cluj-Napoca, Romania*

Short description: In this two-day practical course participants will learn to build, run, and modify reproducible bacterial genomics workflows using Nextflow and Docker. The course also explores cloud computing on Amazon Web Services (AWS) for scalable genomic analyses and the responsible use of AI tools in bioinformatics. Through hands-on exercises, participants will develop practical skills in workflow execution, quality control, cost estimation, documentation, and critical evaluation of results.

**Target audience**

The target audience for this course includes MSc students in Bioinformatics who have completed the *Bioinformatics Methods for Bacterial Genomics* short course and wish to learn how to analyse large numbers of samples using automated workflows and cloud computing. The course is also suitable for early-career researchers, PhD students, bioinformatics analysts, and research software developers who want to develop their skills in reproducible and scalable genomic data analysis.

**Recommended participant background**

The course would be most suitable for participants who have:

-   Basic familiarity with bacterial genomics or sequencing data.

-   Experience using command-line tools or Linux environments.

-   An interest in reproducible research, workflow automation, and cloud-based genomic analysis.
